Introduction

HTML stands for HyperText Markup Language. It is the standard language used to create web pages.

HTML uses tags to describe the different parts of a page, such as headings, paragraphs, links and images.

Every website you visit is built on top of HTML, so it is a great place to start learning web development.

<p>Hello, world!</p>

The line above is a paragraph. It has an opening tag, some text, and a closing tag.

What You Need

You do not need any expensive software to write HTML. A few free tools are enough.

Here is a short checklist to get you started:

  1. A computer with internet access
  2. A text editor such as VS Code or Notepad
  3. A web browser such as Chrome or Firefox
  4. A folder to keep your project files
  5. Curiosity and a bit of patience

Save your file with the .html extension so the browser knows how to open it.

Basic Structure

Every HTML page follows the same basic layout. The head holds information about the page, and the body holds what people see.

<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Welcome!</h1>
  </body>
</html>

Tags are usually written in pairs, and the content goes between them.

Adding Content

Once you have the basic structure, you can fill the body with content. These are some of the most common tags:

  1. h1 to h6 for headings
  2. p for paragraphs
  3. a for links
  4. img for images
  5. ul and ol for lists
<a href="https://www.freecodecamp.org">Visit freeCodeCamp</a>

Try changing the text and refreshing your browser to see the result.

Next Steps

After you are comfortable with HTML, the next thing to learn is CSS, which controls colors, fonts and layout.

Later you can add JavaScript to make your pages interactive.

p { color: blue; }

Keep practicing by building small projects. Every page you make will teach you something new.
